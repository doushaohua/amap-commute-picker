# 租房小区选择助手

**固定通勤终点，在高德地图上连续点选不同小区，快速比较驾车和公共交通用时，再一键跳转查看房源。**

Chrome 扩展 · Manifest V3 · 原生 JavaScript · 无需构建 · 无需配置 API Key · [MIT 开源](LICENSE)

## 为什么做这个工具

租房时，距离近不一定通勤快。想判断一个小区是否合适，往往要在地图里反复输入“小区 → 公司”，分别切换开车、公交，再换下一个小区重新查询。候选小区越多，重复操作越多。

如果是两个人或多人一起住，大家去不同地点上班，还要轮流查看不同方向的通勤，比较起来更麻烦。

这个工具把找房过程变成：**先固定目的地，然后在地图上随意点击候选小区，直接查看到该目的地的通勤结果。** 继续点击另一个小区，就会自动切换起点，无需反复填写路线。先筛出通勤合适的小区，再去房源平台看房。

> 当前每次使用一个统一终点，驾车和公共交通都前往同一地点。多人通勤可依次更改终点，比较各自的通勤方向；暂不支持同时计算多个终点或自动综合排名。

## 核心功能

### 在地图上快速筛选小区

- **先选终点，再选起点**：首次使用按两步引导，直接在地图上选点，不需要输入地址。
- **固定终点，连续换小区**：任意点击地图上的不同小区，自动更新到固定终点的路线与用时；终点只有通过“更改”才会调整。
- **驾车与公共交通一起看**：同时展示两种方式的结果，也可以分别隐藏地图线路，避免重叠。
- **比较不同驾车偏好**：躲避拥堵、不走高速、少收费；地图使用所选出发时刻的预测路况颜色。
- **查看全天用时变化**：预计耗时对比图按15分钟展示，方便比较早一点或晚一点出发的差别。
- **查看多条公交方案**：保留高德返回的公交、地铁方案，默认展示前两条，支持展开更多方案和乘车详情。
- **按上班时间预估**：默认取今天之后的下一个周一至周五08:00（北京时间），也可手动调整未来7天内、15分钟间隔的出发时间。

### 选好小区后，直接查看房源

通勤合适后，点击 **“查看贝壳房源”** 或 **“查看太平洋房源”**，在新标签页打开该小区名称对应的租房搜索页面。

- 贝壳入口保留现有默认筛选参数，可以进入平台后继续调整。
- 太平洋入口按小区名称搜索。
- 两个入口始终跟随当前选中的起点，不必再复制、粘贴小区名称。
- 工具只拼接搜索链接，不抓取房源，不校验是否为住宅小区，也不保证平台一定有匹配结果。

**当前房源入口面向上海。** 通勤结果来自高德网页；其他城市的通勤覆盖取决于高德，但房源入口尚不支持自动切换城市。

## 安装

需要支持 Manifest V3 的桌面版 Chrome（最低111版本）。目前通过“加载未打包的扩展程序”安装，不需要付费服务或自己的服务器。

1. 从 [Releases](https://github.com/doushaohua/amap-commute-picker/releases) 下载扩展 ZIP 并解压；也可以下载仓库源码。
2. 打开 Chrome 的 `chrome://extensions`。
3. 开启右上角“开发者模式”。
4. 点击“加载未打包的扩展程序”，选择解压后**包含 `manifest.json` 的文件夹**。
5. 在扩展菜单中固定“租房小区选择助手”，打开或刷新 [高德地图网页版](https://www.amap.com/)。

加载后请保留扩展所在文件夹。后续更新文件后，在扩展管理页点击“重新加载”，再刷新高德页面。

## 使用

1. 打开助手，点击 **“先在地图上选择终点”**。
2. 在地图上点击工作地点或目的地，终点会自动保存并固定。
3. 按第二步提示，在地图上点击想租住的小区，查看驾车、公共交通路线和用时。
4. **继续点击其他小区**，快速切换起点、比较通勤；无需再次设置终点。
5. 找到合适的小区后，打开贝壳或太平洋查看房源。

可以点击顶部时间修改出发时刻；更换工作地点时，点击终点旁的“更改”，再在地图上选择新终点。“取消”会保留原有选择。

点击浮窗右上角 × 可收起助手，随后通过地图上的开启入口或 Chrome 工具栏图标再次打开。

如果点击的是没有名称的空白位置，仍可查询通勤，但房源按钮不可用；需要查看房源时，请点击地图上有名称的小区地点。

## 数据与隐私

- **无需配置 API Key**，没有内置用户密钥、独立后端或分析上报服务。
- 查询时，选中的起终点坐标和出发时间会发送给高德；使用浏览器已有的高德会话，不读取、导出或保存 Cookie。
- 终点名称、地址、坐标及POI标识只保存在 `chrome.storage.local`，不做云同步。起点和查询结果只保留在当前页面，刷新后清空。
- 只有主动点击房源按钮时，才会打开对应平台并在搜索链接中带上小区名称。
- 不读取浏览历史，不获取其他网站内容，不保存房源或联系人信息。

| 扩展权限 | 用途 |
| --- | --- |
| `scripting` | 从工具栏启用或重新打开高德页面内的助手 |
| `storage` | 保存用户选择的统一终点 |
| `https://www.amap.com/*` | 仅在高德网页运行，连接当前地图 |

更详细的数据流和公开发布检查见 [PRIVACY.md](PRIVACY.md)。

## 当前边界

- 这是独立开发的辅助工具，与高德、贝壳、太平洋没有官方关联。
- 依赖高德网页的地图实例与内部请求，网页更新后可能需要适配。服务验证应在高德原页面手动完成，工具不绕过验证。
- 预测用时会变化，只用于比较和规划；缺失结果会明确提示，不用本地估算填补。
- 默认日期按周一至周五判断，不包含法定节假日与调休规则。手动时间过期后恢复默认，刷新页面也恢复默认时间。
- 任意地图点不一定能通车；没有结果时可选择附近道路或出入口。城际公共交通方案暂不解析。
- 目前主要验证桌面版 Chrome，未验证移动端或所有 Chromium 浏览器。

## 本地开发

```bash
git clone https://github.com/doushaohua/amap-commute-picker.git
cd amap-commute-picker
```

无 npm 依赖，无构建步骤。直接修改源码，在 Chrome 重新加载扩展并刷新高德。

使用支持 `node:test` 的 Node.js 运行测试：

```bash
node --test tests/*.test.cjs
node scripts/check-public.cjs --history
```

| 文件 | 职责 |
| --- | --- |
| `commute-picker.js` | 地图点选、结果控制、浮窗与开启入口 |
| `destination-view.js` / `destination-data.js` | 分步引导、终点校验与本地设置协议 |
| `settings-bridge.js` | 隔离环境中的白名单设置读写 |
| `future-data.js` / `future-chart.js` | 驾车未来用时与15分钟对比图 |
| `route-renderer.js` | 预测路况和多方案路线绘制 |
| `transit-data.js` / `transit-view.js` / `transit-renderer.js` | 公交数据、方案详情与线路 |
| `departure-picker.js` / `panel-scrollbar.js` | 时间选择与浮窗内滚动 |
| `place-links.js` | 地点名称解析与两个房源平台链接 |
| `background.js` / `manifest.json` | 工具栏入口、扩展配置及权限 |
| `tests/` | 使用合成数据和受控时钟的回归测试 |

界面约定见 [design.md](design.md)，验证方法见 [verification.md](verification.md)。欢迎提交 Issue 或 Pull Request；排查问题时请先移除截图、日志中的个人地点和凭证，不要上传浏览器存储、Cookie 或完整网络记录。
